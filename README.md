
# E-Commerce Sales Data Analysis
## Project Idea

This project analyzes an e-commerce sales dataset to identify important business patterns and insights related to customers, products, pricing, marketing, payments, delivery, returns, inventory, suppliers, weather, and seasonality.

The project applies data preprocessing, feature engineering, exploratory data analysis (EDA), and data visualization to transform raw transactional data into meaningful business insights.

## Dataset

The project uses the `Sales_Dataset.xlsx` file.
The dataset contains 7,000 orders and includes information about customers, products, sales, pricing, delivery, returns, inventory, suppliers, weather, and seasonality.

## How to Run
-Place  `Sales_Dataset.xlsx` in the same folder as the notebook.
-Open the Jupyter Notebook.
-Run the cells sequentially from top to bottom.
-To start Jupyter Notebook, run: jupyter notebook
